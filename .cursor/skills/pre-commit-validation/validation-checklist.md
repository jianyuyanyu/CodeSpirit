# 验证检查清单

本文档提供提交前验证的详细检查清单，按优先级组织。

## 检查优先级说明

- 🔴 **严重级别**：必须修复，否则不应提交代码
- 🟡 **重要级别**：建议修复，影响代码质量和可维护性
- 🟢 **建议级别**：最佳实践，可选优化

---

## 🔴 严重级别检查

### 代码审查

- [ ] **安全漏洞**
  - [ ] 无 SQL 注入风险（禁止使用 `FromSqlRaw` 拼接字符串）
  - [ ] 无密码明文存储
  - [ ] 无敏感信息泄露（日志、DTO 返回）
  - [ ] 权限控制正确配置

- [ ] **数据库问题**
  - [ ] 雪花 ID 配置正确（`ValueGeneratedNever()`）
  - [ ] 使用正确的数据库特定 DbContext
  - [ ] 多租户实体实现 `IMultiTenant` 接口
  - [ ] 审计实体继承 `AuditableEntityBase<TKey>`

- [ ] **异步编程**
  - [ ] 无 `Task.Result` 或 `Task.Wait()` 阻塞调用
  - [ ] 所有 I/O 操作使用 `async/await`
  - [ ] 无同步 I/O 操作

### 运行时验证

- [ ] **应用启动**
  - [ ] 所有 API 服务成功启动
  - [ ] 无启动失败的服务
  - [ ] 所有资源状态为 `Running`

- [ ] **数据库连接**
  - [ ] 数据库连接成功
  - [ ] 无数据库连接错误日志
  - [ ] 迁移脚本执行成功（如适用）

- [ ] **错误日志**
  - [ ] 无 Error 级别日志
  - [ ] 无未处理的异常
  - [ ] 无关键服务启动失败

- [ ] **功能验证**
  - [ ] 租户后台可以正常登录
  - [ ] 登录后可以访问管理页面
  - [ ] 无登录功能异常

---

## 🟡 重要级别检查

### 代码审查

- [ ] **多语言支持**
  - [ ] 无硬编码的中文字符串
  - [ ] DTO 属性添加 `[Display]` 特性
  - [ ] 验证消息使用资源文件
  - [ ] 提供中英文资源文件

- [ ] **DTO 规范**
  - [ ] Create/Update DTO 添加验证特性
  - [ ] 查询 DTO 继承 `QueryDtoBase`
  - [ ] 完善 AutoMapper 配置

- [ ] **控制器规范**
  - [ ] 所有方法添加 `[DisplayName]` 特性
  - [ ] 控制器添加 `[Navigation]` 特性
  - [ ] 非标准操作添加 `[Operation]` 特性
  - [ ] 返回类型为 `ActionResult<ApiResponse<T>>`

- [ ] **服务类规范**
  - [ ] 服务类继承 `BaseCRUDService` 或实现 `IBaseCRUDService`
  - [ ] 公共成员添加 XML 文档注释
  - [ ] 实现正确的依赖注入标记接口

- [ ] **EF Core 查询优化**
  - [ ] 只读查询使用 `AsNoTracking()`
  - [ ] 关联数据使用 `Include()` 预加载
  - [ ] 多对多关联使用 `AsSplitQuery()`
  - [ ] 批量操作使用 `ExecuteUpdateAsync` / `ExecuteDeleteAsync`

### 运行时验证

- [ ] **警告日志**
  - [ ] 无 Warning 级别日志（或已确认可接受）
  - [ ] 无配置警告
  - [ ] 无废弃 API 使用警告

- [ ] **资源健康**
  - [ ] 所有资源健康检查通过
  - [ ] 无资源启动超时
  - [ ] 依赖资源正常连接

- [ ] **功能验证**
  - [ ] 登录后主要功能可访问
  - [ ] 页面元素正常加载
  - [ ] 无明显的 UI 错误

---

## 🟢 建议级别检查

### 代码审查

- [ ] **代码注释**
  - [ ] 复杂业务逻辑添加行内注释
  - [ ] 枚举值添加 XML 文档注释
  - [ ] 公共 API 添加完整文档注释

- [ ] **命名规范**
  - [ ] 实体使用单数形式（`User`、`Question`）
  - [ ] DTO 命名符合规范（`Create{Entity}Dto`）
  - [ ] 控制器使用复数形式（`UsersController`）
  - [ ] 服务命名符合规范（`{Entity}Service`）

- [ ] **时间处理**
  - [ ] 数据库存储使用 UTC 时间
  - [ ] 前端显示时转换为本地时间

- [ ] **序列化**
  - [ ] 统一使用 `Newtonsoft.Json`
  - [ ] 避免混用 `System.Text.Json`

- [ ] **性能优化**
  - [ ] 使用投影查询只查询需要的字段
  - [ ] 并发操作使用分布式锁
  - [ ] 异步处理使用事件总线解耦

### 运行时验证

- [ ] **性能相关**
  - [ ] 无性能相关警告
  - [ ] 启动时间合理
  - [ ] 内存使用正常

- [ ] **日志质量**
  - [ ] 日志输出清晰易读
  - [ ] 日志级别设置合理
  - [ ] 关键操作有日志记录

---

## 检查项分类

### 按文件类型

#### 实体文件（Entity）
- [ ] 实现必要的接口（`IMultiTenant`、`IAuditable`）
- [ ] 雪花 ID 配置正确
- [ ] 审计字段配置正确

#### DTO 文件
- [ ] 验证特性完整
- [ ] Display 特性配置多语言
- [ ] 查询 DTO 继承基类

#### 服务文件（Service）
- [ ] 继承基类或实现接口
- [ ] 依赖注入标记正确
- [ ] XML 文档注释完整
- [ ] 异步方法正确实现

#### 控制器文件（Controller）
- [ ] 特性标记完整
- [ ] 返回类型正确
- [ ] 权限控制配置

### 按功能模块

#### 身份认证模块
- [ ] 登录接口正确标记 `[AllowAnonymous]`
- [ ] Token 生成和验证逻辑正确
- [ ] 密码哈希存储

#### 数据访问模块
- [ ] DbContext 配置正确
- [ ] 迁移脚本正确
- [ ] 查询优化到位

#### API 模块
- [ ] 路由配置正确
- [ ] 响应格式统一
- [ ] 错误处理完善

## 快速检查清单

如果时间有限，优先检查以下关键项：

### 必须检查（5分钟）
- [ ] 代码审查无严重安全问题
- [ ] 应用可以正常启动
- [ ] 无 Error 级别日志
- [ ] 租户后台可以登录

### 建议检查（10分钟）
- [ ] 代码审查无重要问题
- [ ] 无 Warning 级别日志
- [ ] 主要功能可访问

### 完整检查（30分钟）
- [ ] 完成所有严重和重要级别检查
- [ ] 完成建议级别检查（可选）
- [ ] 生成完整验证报告

## 使用说明

1. **执行检查**：按照清单逐项检查
2. **记录问题**：在"检查结果记录"部分记录发现的问题
3. **优先级修复**：先修复严重问题，再处理重要问题
4. **重新验证**：修复后重新运行验证流程
