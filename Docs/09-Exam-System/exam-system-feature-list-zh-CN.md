# 考试系统业务功能清单

## 1. 用户角色定义

### 1.1 系统角色

| 角色 | 描述 | 主要职责 |
|------|------|----------|
| 超级管理员 | 系统最高权限用户 | 租户管理、系统配置、全局监控 |
| 租户管理员 | 租户级别管理员 | 租户内用户管理、权限分配、系统配置 |
| 考试管理员 | 考试业务管理员 | 题目管理、试卷管理、考试设置 |
| 监考员 | 考试监督员 | 考试监控、异常处理、考场管理 |
| 教师/出题员 | 题目创建者 | 题目编写、分类管理、质量审核 |
| 考生 | 参考人员 | 参加考试、练习答题、查看成绩 |

## 2. 题目管理功能

### 2.1 题目基础管理

#### 2.1.1 题目CRUD操作
- ✅ **新增题目**
  - 支持单选题、多选题、判断题等题型
  - 富文本编辑器支持图片、公式
  - 题目难度等级设置（1-5级）
  - 题目标签和关键词管理
  
- ✅ **编辑题目**
  - 在线编辑题目内容和选项
  - 版本控制，保留历史版本
  - 修改原因记录
  - 预览功能
  
- ✅ **删除题目**
  - 软删除机制
  - 使用状态检查（已用于试卷的题目提示风险）
  - 批量删除操作
  - 删除原因记录

- ✅ **题目查询**
  - 多条件组合查询（题型、难度、分类、关键词）
  - 全文搜索支持
  - 高级筛选器
  - 导出查询结果

#### 2.1.2 题目分类管理
- ✅ **分类层级管理**
  - 支持多级分类结构
  - 分类树形展示
  - 拖拽排序
  - 分类统计信息

- ✅ **分类操作**
  - 新增/编辑/删除分类
  - 分类批量移动
  - 分类合并功能
  - 分类使用统计

#### 2.1.3 题目版本管理
- ✅ **版本控制**
  - 每次修改自动创建新版本
  - 版本对比功能
  - 版本回滚操作
  - 版本使用状态跟踪

- ✅ **版本审核**
  - 版本审批流程
  - 审核意见记录
