# 成绩比例换算技术实现方案

## 1. 需求分析

### 业务需求
- 支持将非标准分值（如120分、150分等）的试卷成绩按特定比例自动转换为百分制标准分
- 满足国家职业标准对考试成绩「百分制」的强制要求
- 在试卷生成时预先设置换算规则，在成绩计算时自动应用

### 技术需求
- 扩展`GenerateRandomExamPaperDto`支持成绩换算配置
- 扩展数据模型支持成绩换算规则存储
- 实现成绩换算服务和逻辑
- 确保换算后的成绩仍然符合及格标准

## 4. 简化的通过率统计逻辑

### 4.1 优化思路

**核心设计理念**：保持 `PassScore` 字段作为"有效及格分"，所有现有逻辑无需修改

**字段语义重新定义**：
- **未启用成绩换算**：`PassScore` = 原始及格分
- **启用成绩换算**：`PassScore` = 换算后及格分
- **新增字段**：`OriginalPassScore` = 原始及格分（仅用于记录和显示）

### 4.2 试卷创建时的PassScore自动更新

**修改文件：`Services/Implementations/ExamPaperService.cs`**

在`GenerateRandomExamPaperAsync`方法中添加PassScore自动更新逻辑：
```csharp
// 在创建试卷时，根据成绩换算设置自动更新PassScore
if (createDto.EnableScoreConversion)
{
    // 保存原始及格分
    examPaper.OriginalPassScore = createDto.PassScore;
    
    // 将PassScore更新为换算后的及格分
    examPaper.PassScore = createDto.ConversionTargetPassScore;
    
    // 设置其他换算相关字段
    examPaper.EnableScoreConversion = true;
    examPaper.ConversionTargetFullScore = createDto.ConversionTargetFullScore;
    examPaper.ConversionDecimalPlaces = createDto.ConversionDecimalPlaces;
    examPaper.ConversionRatio = _scoreConversionService.CalculateConversionRatio(
        createDto.TotalScore, createDto.ConversionTargetFullScore);
}
else
{
    // 未启用换算，PassScore保持原始值
    examPaper.OriginalPassScore = createDto.PassScore;
    examPaper.PassScore = createDto.PassScore;
}
```

### 4.3 无需修改现有通过率统计逻辑

**优势**：所有现有的通过率统计代码都不需要修改，因为：
- `ExamRecordService` 中的 `IsPassed` 计算：`examRecord.IsPassed = totalScore >= examPaper.PassScore` ✅
- `ExamSettingService` 中的通过率统计：`Count(r => r.Score >= x.ExamPaper.PassScore)` ✅  
- `ExamStatisticsService` 中的统计分析：`Count(r => r.IsPassed)` ✅

**原因**：`PassScore` 字段始终表示当前有效的及格分，无论是否启用成绩换算。

### 5.2 成绩换算服务实现

**新增文件：`Services/Implementations/ScoreConversionService.cs`**
```csharp
using CodeSpirit.Core;
using CodeSpirit.ExamApi.Services.Interfaces;

namespace CodeSpirit.ExamApi.Services.Implementations;

/// <summary>
/// 成绩换算服务实现
/// </summary>
public class ScoreConversionService : IScoreConversionService
{
    /// <summary>
    /// 计算换算后的成绩
    /// </summary>
    public double ConvertScore(double originalScore, int originalFullScore, int targetFullScore, int decimalPlaces = 1)
    {
        if (originalFullScore <= 0)
            throw new AppServiceException(400, "原始满分必须大于0");

        if (targetFullScore <= 0)
            throw new AppServiceException(400, "目标满分必须大于0");

        // 计算换算比例：目标满分 / 原始满分
        double conversionRatio = (double)targetFullScore / originalFullScore;
        
        // 换算成绩
        double convertedScore = originalScore * conversionRatio;
        
        // 保留指定的小数位数
        return Math.Round(convertedScore, decimalPlaces);
    }

    /// <summary>
    /// 计算换算后的及格分数
    /// </summary>
    public double ConvertPassScore(int originalPassScore, int originalFullScore, int targetFullScore, int decimalPlaces = 1)
    {
        return ConvertScore(originalPassScore, originalFullScore, targetFullScore, decimalPlaces);
    }

    /// <summary>
    /// 验证换算规则的有效性
    /// </summary>
    public (bool IsValid, string ErrorMessage) ValidateConversionRule(int originalFullScore, int targetFullScore, int targetPassScore, int decimalPlaces)
    {
        if (targetFullScore <= 0)
            return (false, "目标满分必须大于0");

        if (targetPassScore < 0)
            return (false, "目标及格分不能小于0");

        if (targetPassScore > targetFullScore)
            return (false, "目标及格分不能大于目标满分");

        if (decimalPlaces < 0 || decimalPlaces > 2)
            return (false, "小数保留位数必须在0-2之间");

        if (originalFullScore <= 0)
            return (false, "原始满分必须大于0");

        return (true, string.Empty);
    }

    /// <summary>
    /// 自动生成换算描述
    /// </summary>
    public string GenerateConversionDescription(int originalFullScore, int targetFullScore, int decimalPlaces)
    {
        var ratio = CalculateConversionRatio(originalFullScore, targetFullScore);
        var ratioDisplay = Math.Round((double)ratio, 3);

        return $"将{originalFullScore}分制转换为{targetFullScore}分制，" +
               $"换算比例为{targetFullScore}/{originalFullScore}={ratioDisplay}，" +
               $"小数保留{decimalPlaces}位";
    }

    /// <summary>
    /// 计算换算比例
    /// </summary>
    public decimal CalculateConversionRatio(int originalFullScore, int targetFullScore)
    {
        if (originalFullScore <= 0)
            throw new AppServiceException(400, "原始满分必须大于0");

        if (targetFullScore <= 0)
            throw new AppServiceException(400, "目标满分必须大于0");

        return (decimal)targetFullScore / originalFullScore;
    }
}
```

```csharp
// 在SubmitExamAsync和相关评分方法中添加成绩换算逻辑
private async Task ApplyScoreConversion(ExamRecord examRecord, double originalScore)
{
    var examPaper = examRecord.ExamSetting.ExamPaper;
    
    // 保存原始成绩
    examRecord.OriginalScore = originalScore;
    
    if (!examPaper.EnableScoreConversion || 
        examPaper.ConversionTargetFullScore == null ||
        examPaper.ConversionRatio == null)
    {
        // 未启用换算，原始成绩即为最终成绩
        examRecord.Score = originalScore;
        examRecord.IsScoreConverted = false;
        examRecord.ScoreConversionRatio = null;
    }
    else
    {
        // 应用换算规则
        var convertedScore = _scoreConversionService.ConvertScore(
            originalScore, 
            examPaper.TotalScore, 
            examPaper.ConversionTargetFullScore.Value,
            examPaper.ConversionDecimalPlaces);
        
        examRecord.Score = convertedScore; // Score字段存储最终显示成绩（换算后）
        examRecord.IsScoreConverted = true;
        examRecord.ScoreConversionRatio = examPaper.ConversionRatio;
    }
    
    // 计算是否通过（基于PassScore字段，无需额外计算）
    // PassScore字段已经根据是否启用换算设置为正确的及格分
    examRecord.IsPassed = examRecord.Score >= examPaper.PassScore;
}

// 修改现有的评分方法，使用新的换算逻辑
// 例如在SubmitExamAsync方法中：
// 计算原始分数
double originalTotalScore = CalculateOriginalScore(examRecord);

// 应用成绩换算
await ApplyScoreConversion(examRecord, originalTotalScore);
```

```csharp
// 在映射配置中添加
CreateMap<GenerateRandomExamPaperDto, ExamPaper>()
    .ForMember(dest => dest.ConversionRatio, opt => opt.Ignore()); // 在服务层手动计算

    .ForMember(dest => dest.ConversionDescription, opt => opt.MapFrom<ConversionDescriptionResolver>());

// 自定义解析器，用于自动生成换算描述
public class ConversionDescriptionResolver : IValueResolver<ExamPaper, ExamPaperDto, string>
{
    private readonly IScoreConversionService _scoreConversionService;

    public ConversionDescriptionResolver(IScoreConversionService scoreConversionService)
    {
        _scoreConversionService = scoreConversionService;
    }

    public string Resolve(ExamPaper source, ExamPaperDto destination, string destMember, ResolutionContext context)
    {
        if (!source.EnableScoreConversion || !source.ConversionTargetFullScore.HasValue)
        {
            return "未启用成绩换算";
        }

        return _scoreConversionService.GenerateConversionDescription(
            source.TotalScore,
            source.ConversionTargetFullScore.Value,
            source.ConversionDecimalPlaces);
    }
}
```

## 16. 数据类型合理性分析

### 16.1 数据类型选择说明

**整型字段（int）**：
- `ConversionTargetFullScore` - 目标满分：通常为整数值（如100、120），使用int合理
- `ConversionTargetPassScore` - 目标及格分：通常为整数值（如60、72），使用int合理  
- `ConversionDecimalPlaces` - 小数保留位数：0-2的整数，使用int合理

**浮点型字段（double）**：
- `OriginalScore` - 原始成绩：可能包含小数，使用double合理
- `ConvertedScore` - 换算后成绩：可能包含小数，使用double合理
- `Score` - 最终成绩：向后兼容字段，使用double合理

**高精度小数（decimal）**：
- `ConversionRatio` - 换算比例：需要精确计算，避免浮点误差，使用decimal合理
- `ScoreConversionRatio` - 换算比例记录：同上，使用decimal合理

### 16.2 数据类型优势

- **避免精度丢失**：换算比例使用decimal确保计算精度
- **兼容性良好**：成绩字段使用double与现有系统保持一致
- **存储效率**：整数配置使用int，节省存储空间
- **查询性能**：合适的数据类型便于数据库索引和查询优化

```csharp
using CodeSpirit.ExamApi.Services.Interfaces;
using CodeSpirit.ExamApi.Models;
using CodeSpirit.ExamApi.Dtos.ExamPaper;
using CodeSpirit.ExamApi.Dtos.ExamRecord;
using Newtonsoft.Json.Linq;

namespace CodeSpirit.ExamApi.Services.Implementations;

/// <summary>
/// 成绩显示服务实现
/// </summary>
public class ScoreDisplayService : IScoreDisplayService
{
    private readonly IScoreConversionService _scoreConversionService;
    
    public ScoreDisplayService(IScoreConversionService scoreConversionService)
    {
        _scoreConversionService = scoreConversionService;
    }
    
    /// <summary>
    /// 构建成绩显示信息
    /// </summary>
    public ScoreDisplayInfo BuildScoreDisplay(double originalScore, int originalFullScore, ExamPaperDto examPaper)
    {
        var scoreDisplay = new ScoreDisplayInfo
        {
            OriginalScore = originalScore,
            OriginalFullScore = originalFullScore,
            IsScoreConverted = examPaper.EnableScoreConversion
        };
        
        if (examPaper.EnableScoreConversion && examPaper.ConversionTargetFullScore.HasValue)
        {
            // 计算换算后成绩
            var convertedScore = _scoreConversionService.ConvertScore(
                originalScore,
                originalFullScore,
                examPaper.ConversionTargetFullScore.Value,
                examPaper.ConversionDecimalPlaces);
            
            scoreDisplay.FinalScore = convertedScore;
            scoreDisplay.FinalFullScore = examPaper.ConversionTargetFullScore.Value;
            scoreDisplay.ConversionRatio = examPaper.ConversionRatio;
            scoreDisplay.ConversionDescription = _scoreConversionService.GenerateConversionDescription(
                originalFullScore,
                examPaper.ConversionTargetFullScore.Value,
                examPaper.ConversionDecimalPlaces);
            
            // 基于换算后成绩判断是否通过
            var convertedPassScore = examPaper.ConversionTargetPassScore ?? 60;
            scoreDisplay.IsPassed = convertedScore >= convertedPassScore;
        }
        else
        {
            // 未启用换算，使用原始成绩
            scoreDisplay.FinalScore = originalScore;
            scoreDisplay.FinalFullScore = originalFullScore;
            scoreDisplay.IsPassed = originalScore >= examPaper.PassScore;
        }
        
        return scoreDisplay;
    }
    
    /// <summary>
    /// 构建成绩显示信息（考试记录版本）
    /// </summary>
    public ScoreDisplayInfo BuildScoreDisplay(ExamRecordDto examRecord, ExamPaperDto examPaper)
    {
        var scoreDisplay = new ScoreDisplayInfo
        {
            OriginalScore = examRecord.OriginalScore ?? examRecord.Score ?? 0,
            OriginalFullScore = examPaper.TotalScore,
            FinalScore = examRecord.Score ?? 0, // Score字段存储最终显示成绩
            IsScoreConverted = examRecord.IsScoreConverted,
            IsPassed = examRecord.IsPassed
        };
        
        if (examRecord.IsScoreConverted)
        {
            // 已启用换算，Score字段存储的是换算后成绩
            scoreDisplay.FinalFullScore = examPaper.ConversionTargetFullScore ?? examPaper.TotalScore;
            scoreDisplay.ConversionRatio = examRecord.ScoreConversionRatio;
            
            if (examPaper.ConversionTargetFullScore.HasValue)
            {
                scoreDisplay.ConversionDescription = _scoreConversionService.GenerateConversionDescription(
                    examPaper.TotalScore,
                    examPaper.ConversionTargetFullScore.Value,
                    examPaper.ConversionDecimalPlaces);
            }
        }
        else
        {
            // 未启用换算，Score字段存储的是原始成绩
            scoreDisplay.FinalFullScore = examPaper.TotalScore;
        }
        
        return scoreDisplay;
    }
    
    /// <summary>
    /// 生成成绩显示HTML片段
    /// </summary>
    public string GenerateScoreHtml(ScoreDisplayInfo scoreDisplay, bool showDetails = true)
    {
        var html = new StringBuilder();
        
        if (scoreDisplay.IsScoreConverted)
        {
            // 显示换算后成绩（主要显示）
            html.AppendLine($"<div class=\"score-display converted\">");
            html.AppendLine($"  <div class=\"main-score\">");
            html.AppendLine($"    <span class=\"score-value\">{scoreDisplay.FinalScore:F1}</span>");
            html.AppendLine($"    <span class=\"score-unit\">/{scoreDisplay.FinalFullScore}分</span>");
            html.AppendLine($"    <span class=\"score-badge converted\">已换算</span>");
            html.AppendLine($"  </div>");
            
            if (showDetails)
            {
                html.AppendLine($"  <div class=\"original-score\">");
                html.AppendLine($"    <small>原始成绩：{scoreDisplay.OriginalScore:F1}/{scoreDisplay.OriginalFullScore}分</small>");
                html.AppendLine($"  </div>");
                html.AppendLine($"  <div class=\"conversion-note\">");
                html.AppendLine($"    <small class=\"text-muted\">{scoreDisplay.ConversionDescription}</small>");
                html.AppendLine($"  </div>");
            }
            
            html.AppendLine($"</div>");
        }
        else
        {
            // 显示原始成绩
            html.AppendLine($"<div class=\"score-display original\">");
            html.AppendLine($"  <div class=\"main-score\">");
            html.AppendLine($"    <span class=\"score-value\">{scoreDisplay.FinalScore:F1}</span>");
            html.AppendLine($"    <span class=\"score-unit\">/{scoreDisplay.FinalFullScore}分</span>");
            html.AppendLine($"  </div>");
            html.AppendLine($"</div>");
        }

    }

    /// 生成成绩显示的Amis配置
    /// </summary>

    {
        if (scoreDisplay.IsScoreConverted)
        {
            return new JObject
            {
                ["type"] = "html",
                ["className"] = $"{cssClass} converted",
                ["html"] = $@"
                    <div class=""score-main"">
                        <div class=""score-value"">{scoreDisplay.FinalScore:F1}</div>
```

```csharp
                typeScore, examPaper.TotalScore, scoreDisplay.ConvertedFullScore.Value, examPaper.ConversionDecimalPlaces);
            var convertedTypeTotalScore = _scoreConversionService.ConvertScore(
                typeTotalScore, examPaper.TotalScore, scoreDisplay.ConvertedFullScore.Value, examPaper.ConversionDecimalPlaces);
                
            htmlBuilder.AppendLine($"        <td style=\"color: #666;\">{typeScore:F1}/{typeTotalScore}</td>");
            htmlBuilder.AppendLine($"        <td style=\"color: #52c41a; font-weight: bold;\">{convertedTypeScore:F1}/{convertedTypeTotalScore:F1}</td>");
        }
        else
        {
            htmlBuilder.AppendLine($"        <td>{typeScore:F1}/{typeTotalScore}</td>");
        }
        
        htmlBuilder.AppendLine("      </tr>");
    }

    htmlBuilder.AppendLine("    </table>");
    htmlBuilder.AppendLine("  </div>");

    // [其余题目内容显示代码保持不变]

    htmlBuilder.AppendLine("</body>");
    htmlBuilder.AppendLine("</html>");

    return htmlBuilder.ToString();
}
```
